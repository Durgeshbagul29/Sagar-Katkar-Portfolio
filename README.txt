# Sagar Katkar - Portfolio Website

A modern, professional portfolio website built with React, Vite, and Bun, featuring stunning animations and a sleek dark theme.

## 🚀 Quick Start

### Prerequisites
- Bun (recommended) or npm/yarn

### Installation

1. Install dependencies:
   ```bash
   bun install
   ```

2. Start development server:
   ```bash
   bun run dev
   ```

3. Open your browser:
   ```
   http://localhost:5173
   ```

## 📦 Build Commands

- **Development**: `bun run dev` - Start dev server with hot reload
- **Build**: `bun run build` - Build for production
- **Preview**: `bun run preview` - Preview production build

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Runtime**: Bun
- **Styling**: Tailwind CSS (via CDN)
- **Routing**: React Router DOM
- **Animations**: React Transition Group + Custom CSS
- **Email Service**: EmailJS

## ✨ Features

- Modern dark theme design
- Smooth page transitions
- Professional animations
- Responsive layout
- Certificate gallery
- Contact form with email integration
- Back to top button
- Auto scroll to top on page navigation

## 📝 Notes

- Tailwind CSS is loaded via CDN (no config file needed)
- Dark theme is the default and only theme
- Smooth scrolling enabled throughout
- Optimized for performance
